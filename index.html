Soy Carlos Julio Leyva Baquero, desarrollador de software radicado en Bogotá, Colombia. Durante los últimos 5 años he trabajado en SIPSE S.A.S. diseñando, construyendo y manteniendo sistemas de información web empresariales de misión crítica, con foco en estabilidad, modularidad y rendimiento.

Mi stack principal gira alrededor de PHP (Laravel), MySQL, SQL Server, PostgreSQL, jQuery y Bootstrap, complementado con Vue.js y Tailwind CSS en el frontend. Aplico principios SOLID y Clean Code como base de cada solución.

Actualmente curso el 6.° semestre de Ingeniería de Software en UNINPAHU, complementando la formación técnica previa del SENA con arquitectura de software, gestión de proyectos y patrones estructurales de sistemas.
